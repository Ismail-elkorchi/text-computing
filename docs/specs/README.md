# Specifications

This directory stores public platform specifications and repository-level
contract documents.

A specification document must state its scope, version, normative language, and verification expectations before implementation depends on it.

## Documents

- [`text-computing-platform.md`](text-computing-platform.md) — accepted product
  architecture and runtime boundaries for Text Computing, Capability Packs, and
  Textpack Forge.
- [`textpack-capability-tiers.md`](textpack-capability-tiers.md) — availability
  and inference-depth claims for Capability Packs.
- [`textcorpus-collection-contract.md`](textcorpus-collection-contract.md) — deterministic corpus collection and explicit-token fingerprint contract.
