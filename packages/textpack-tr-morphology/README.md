# `@ismail-elkorchi/textpack-tr-morphology`

Small Turkish morphology reference pack for agglutinative-language coverage.

The package exports final `manifest`, `resources`, and default `{ manifest, resources }`.

## Resources

- `morph-tr-demo`: agglutinative morphology examples
- `fst-tr-demo`: finite-state morphology examples
- `lexicon-tr-demo`: Turkish lemma and part-of-speech examples

## Verification

`npm -w @ismail-elkorchi/textpack-tr-morphology run -s test:all`
