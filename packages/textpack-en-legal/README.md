# @ismail-elkorchi/textpack-en-legal

This package provides the pack:en-legal reference resource pack for `@ismail-elkorchi/textpack` alpha validation.

## Scope

Reference legal-domain resources for deterministic pack loading, pack-backed rules, lookup, and
package validation. It is not comprehensive legal-domain coverage.

## Resources

- `profiles`: `profile-en-legal`
- `stopwords`: `stopwords-en-legal`
- `rules`: `rule-en-legal`
- `lexicons`: `lexicon-en-legal`
- `gazetteers`: `gazetteer-en-legal`
- `tagsets`: `tagset-en-legal-lite`
- `morphology`: `morph-en-legal`
- `transducers`: `transducer-en-legal`
- `structures`: `structure-en-legal`
- `benchmarks`: `benchmark-en-legal-smoke`

## Verification

`npm -w @ismail-elkorchi/textpack-en-legal run -s test`
