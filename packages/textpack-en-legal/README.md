# `@ismail-elkorchi/textpack-en-legal`

English legal-domain reference resources for final `@ismail-elkorchi/textpack` workflows.

The package exports final `manifest`, `resources`, and default `{ manifest, resources }`.

## Resources

- `profile-en-legal`: quality profile
- `rule-en-legal`: legal rule set
- `termbase-en-legal`: legal termbase
- `stoplist-en-legal`: legal stoplist
- `gazetteer-en-legal`: legal gazetteer
- `tagset-en-legal-lite`: dataset
- `morph-en-legal`: morphology lookup data
- `fst-en-legal`: finite-state examples
- `grammar-en-legal`: legal grammar examples
- `corpus-en-legal-smoke`: small legal smoke corpus

## Verification

`npm -w @ismail-elkorchi/textpack-en-legal run -s test:all`
