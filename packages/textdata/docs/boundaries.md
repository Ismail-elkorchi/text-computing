# Boundaries

`textdata` loads, streams, converts, splits, and writes datasets. Corpus statistics belong to `textcorpus`. Model training belongs to `textclassical`. Pipeline execution belongs to `textpipeline`. Search indexing belongs to `textsearch`. Knowledge linking belongs to `textkb`.

Runtime inputs and outputs are caller-owned values and streams. Shipped runtime code does not use Node-only file-system APIs.
