# Imports

Use the root entrypoint for common APIs:

```ts
import { applyDown, compileLexicon, compileRegex } from "@ismail-elkorchi/text-computing/finite-state";
```

Focused entrypoints are available for `automaton`, `transducer`, `compile`, `regex`, `rewrite`,
`lexc`, `twol`, `apply`, `weight`, `morph`, and `spell`.
