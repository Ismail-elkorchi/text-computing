# Imports

Use the root for common APIs and focused subpaths for task areas:

```ts
import { trainClassifier } from "@ismail-elkorchi/text-computing/learning";
import { fitVectorizer } from "@ismail-elkorchi/text-computing/learning/vectorize";
import { trainSequenceTagger } from "@ismail-elkorchi/text-computing/learning/sequence";
```

No other public subpath is part of the final package surface.
