# `@ismail-elkorchi/textpack-corpus-demo-en`

Small English corpus reference pack.

The package exports final `manifest`, `resources`, and default `{ manifest, resources }`.

## Resources

- `corpus-demo-en-lines`: small English corpus lines
- `dataset-demo-en-metadata`: corpus metadata dataset

## Verification

`npm -w @ismail-elkorchi/textpack-corpus-demo-en run -s test:all`
