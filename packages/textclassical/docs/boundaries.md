# Boundaries

`textclassical` implements classical statistical NLP. It does not implement transformers, neural
embeddings, neural translation, neural generation, corpus stores, dataset readers, search indexes,
KB reasoning, pipeline orchestration, rule execution, text normalization, pack discovery, file
loading, or network loading.

The package depends only on final lower packages: `textfacts`, `textdoc`, `textlex`, and `textfst`.
