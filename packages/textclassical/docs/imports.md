# Imports

Use the root for common APIs and focused subpaths for task areas:

```ts
import { trainClassifier } from "@ismail-elkorchi/textclassical";
import { fitVectorizer } from "@ismail-elkorchi/textclassical/vectorize";
import { trainSequenceTagger } from "@ismail-elkorchi/textclassical/sequence";
```

No other public subpath is part of the final package surface.
