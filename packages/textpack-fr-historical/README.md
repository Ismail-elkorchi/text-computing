# `@ismail-elkorchi/textpack-fr-historical`

Small French historical spelling reference pack.

The package exports final `manifest`, `resources`, and default `{ manifest, resources }`.

## Resources

- `profile-fr-historical-normalization`: nineteenth-century spelling normalization profile
- `lexicon-fr-historical`: historical-to-modern French spelling examples
- `fst-fr-historical`: finite-state spelling normalization examples

## Verification

`npm -w @ismail-elkorchi/textpack-fr-historical run -s test:all`
