# @ismail-elkorchi/textrules examples

Runnable repository examples:

- [`../../../examples/textrules-rule-bundle-consumer.mjs`](../../../examples/textrules-rule-bundle-consumer.mjs)
  compiles a general rule bundle and runs span-pattern, annotation-pattern, lexicon, validation,
  transducer, rewrite, provenance, ambiguity, and conflict-policy settings through package APIs.
- [`../../../examples/textrules-textpack-consumer.mjs`](../../../examples/textrules-textpack-consumer.mjs)
  loads textpack resources and runs pack-backed `textrules` annotations through `textpipeline`.
