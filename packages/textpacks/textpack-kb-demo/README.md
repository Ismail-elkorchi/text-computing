# `@ismail-elkorchi/textpack-kb-demo`

Small knowledge-base reference pack.

The package exports final `manifest`, `resources`, and default `{ manifest, resources }`.

## Resources

- `kb-demo-entities`: demo knowledge-base entities
- `ontology-demo-relations`: demo ontology relations
- `lexicon-demo-aliases`: lexical aliases linked to KB entities

## Verification

`npm -w @ismail-elkorchi/textpack-kb-demo run -s test:all`
