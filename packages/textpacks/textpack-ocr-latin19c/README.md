# `@ismail-elkorchi/textpack-ocr-latin19c`

Small OCR/noisy text reference pack for Latin-script nineteenth-century documents.

The package exports final `manifest`, `resources`, and default `{ manifest, resources }`.

## Resources

- `profile-ocr-latin19c`: OCR normalization profile
- `quality-ocr-latin19c`: Latin-script OCR quality/confusable profile
- `fst-ocr-latin19c`: finite-state OCR normalization examples

## Verification

`npm -w @ismail-elkorchi/textpack-ocr-latin19c run -s test:all`
